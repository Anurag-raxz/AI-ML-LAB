# Data Preprocessing using Python (Google Colab)

## Overview

This project demonstrates a complete data preprocessing workflow using Python in Google Colab. The objective is to clean, transform, analyze, and prepare a dataset for machine learning by applying various preprocessing techniques.

The dataset used in this project is:

**Combined12.csv**

---

## Objectives

The preprocessing tasks performed include:

1. Importing the required Python libraries.
2. Loading the dataset into a Pandas DataFrame.
3. Displaying dataset information and summary statistics.
4. Checking the dataset shape.
5. Identifying missing values.
6. Handling missing values using appropriate imputation techniques.
7. Removing duplicate records.
8. Encoding categorical variables.
9. Detecting and removing outliers using the IQR method.
10. Generating a correlation matrix and heatmap.
11. Creating new features using feature engineering.
12. Converting data types where necessary.
13. Cleaning inconsistent and noisy data.
14. Splitting the dataset into training and testing sets.
15. Balancing the training dataset using SMOTE or Random Oversampling.
16. Visualizing numerical feature distributions before and after preprocessing.
17. Comparing the dataset before and after preprocessing.
18. Saving the cleaned dataset as a new CSV file.
19. Documenting each preprocessing step with outputs.
